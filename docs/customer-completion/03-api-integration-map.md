# 03 — API integration map

Base path dùng bởi Mobile: `ApiConfig` → `/api/v1/`. Backend `TransformResponseInterceptor` bọc response thành `{success, statusCode, data, timestamp}`; repository unwrap envelope rồi map DTO. Các lỗi HTTP được đổi qua `ApiException.fromDio` ở repository tương ứng.

| Web UI / hook / service | Backend implementation / contract | Mobile repository/state / screen | Request and mapping notes |
|---|---|---|---|
| Login/signup, `queries/useAuth.ts` → `services/backend/auth.ts` | `auth.controller.ts`: `POST auth/login`, `POST auth/register` | `ApiAuthRepository` → `AuthUserNotifier` → login/signup | Parse `data.access_token`, `refresh_token`, `expires_in`, `user`; giữ token trong `AuthSessionStore`. |
| Session refresh/logout | `POST auth/refresh`, `POST auth/logout` | `SessionInterceptor`, `ApiAuthRepository.logout` | Refresh được single-flight; response envelope unwrap; GET được retry một lần; write không được phát lại. Logout luôn dọn local session. |
| Password reset/email verify/change | `auth.controller.ts` | `ApiAuthFlowRepository`, auth/account settings | DTO field names theo BE (`email`, `otp`, `reset_token`, `new_password`, `confirm_password`). Protected email OTP dùng access token. |
| Google OAuth | `google-auth.controller.ts` | `ApiAuthFlowRepository.getGoogleAuthorizationUrl/exchangeGoogleCode` | `/login` trả URL; `/exchange?code=...` lưu session. Thiếu mobile callback URI/deep link nên không có flow hoàn chỉnh. |
| User/customer profile | `profile.ts`, `useProfile` | `ApiAuthRepository` → profile settings | `GET/PATCH users/me` (`fullname`, optional `phone_number`, `gender`, `dob`, `avatar_url`); `GET/PATCH customers/me` (`location`, profile preferences). DOB dùng `yyyy-MM-dd`. `address`/`saveAsDefault` thay đổi bị từ chối vì DTO không có field. |
| Notification preferences | `NotificationSettings.tsx`, `useProfile` | `ApiCustomerNotificationPreferencesRepository` → Riverpod notifier → `SettingsScreen` | `GET users/me`; `PATCH users/me` với đủ boolean `booking_updates/messages/promotions/email_digest`. Defaults khớp Web: hai mục đầu true, hai mục cuối false. |
| Avatar upload | Profile settings | `ApiMediaUploadRepository` → `ApiAuthRepository.updateAvatar` | Reserve `media/upload-url` (`content_type`, `file_size`, `visibility: public`), PUT bytes vào signed HTTPS URL không kèm API bearer, complete upload, poll `media/:id` tới `ready`, sau đó PATCH avatar URL. |
| Photographer listing/search/filter/sort | `routes/Photographers`, `queries/usePhotographers.ts`, `services/backend/photographers.ts`, `lib/photographer-filters.ts` | `ApiPhotographerRepository` → discovery controller/filter sheet/screen | Browse mặc định dùng `photographers/top-rated`; filter dùng page `GET photographers?limit=100&offset=...` với `location/min_rating` làm prefilter, sau đó local search/city/rating, multi-style OR, price (starting plan/price), experience và sort trước khi phân trang 9 items. Style codes map theo Web `STYLE_LABELS`. DTO không có query riêng cho các local filters. Ngày rảnh không lọc vì Web directory mapper trả `availableDates: []`; Backend availability chỉ theo từng photographer. |
| Recommendations | `Overview`/photographer service | `CustomerRecommendationsRepository` → customer home provider | `GET customers/me/recommendations?limit=6&offset=0`; unwrap envelope rồi map items. |
| Photographer detail | profile route + plan/portfolio/review queries | `ApiPhotographerDetailRepository` → detail screen/tabs | Profile, plans, portfolio page, reviews, rating summary và availability được gọi riêng; `from/to` theo giờ Việt Nam. Portfolio detail cung cấp cover/download URLs. |
| Booking create/list/detail/cancel/timeline/confirm | `useBookings`, `services/backend/bookings.ts` | `ApiBookingRepository`, booking controller/detail/dialog | Create gửi `photographer_id`, `booking_plan_id`, `location`, `from`, `to`; list phân trang; cancel gửi reason; confirm receipt dùng action endpoint. Cancellation preview mới map `booking_id`, `refundable_amount_vnd`, `refund_requires_admin_review`. |
| Deposit/remaining/payment status/QR/history | `Deposit.tsx`, `Payment.tsx`, payment services | `BookingPaymentRepository` → payment screens and paid-total provider | `POST bookings/:id/payments/deposit|remaining` với payment method + idempotency key; `GET payments/:id`, `/qr`, booking payments history. UI cần status settled từ Backend trước khi báo thành công. |
| Wallet/ledger/withdrawal | `useWallet`, `WithdrawDialog` → `services/wallet.ts`, `services/backend/payments.ts` | `ApiCustomerWalletRepository` → wallet screen/withdrawal dialog | `GET wallet`; `GET wallet/ledger?limit=100&offset=...`; parse amount/delta; `POST wallet/withdrawals` với `amount`, `reason`, `payout_destination.{bank_code,account_number,account_name}`, `idempotency_key`. Yêu cầu có min 10.000 VND và chờ admin review; Mobile refresh balance/ledger sau thành công. |
| Gallery/download | `DeliveryGallery` | `BookingGalleryRepository`, `ApiDeliveryMediaRepository` → gallery screen | `GET bookings/:id/gallery`; `GET bookings/:id/gallery/download` chọn download URL theo media ID; byte download dùng URL/response tương ứng. |
| Review submit/history | `Reviews.tsx`, `useReviews`, `services/reviews.ts` | `ApiCustomerReviewsRepository` + `CustomerReviewsNotifier` → reviews screen | `POST bookings/:id/reviews` với `rating`, `punctuality_rating`, `attitude_rating`, comment; `GET customers/me/reviews` theo pages 100. Duplicate/eligibility do BE quyết định; HTTP 409 được nêu thành lỗi nghiệp vụ. |
| Notifications | `useNotifications`, `useNotificationRealtime` | notification center/realtime client | Service URL cấu hình độc lập bằng `NOTIFICATION_API_URL`; preferences riêng đã dùng `/users/me`. Chưa xác minh live service. |
| Chat | `useMessages` → `services/messages.ts` | `ApiCustomerChatRepository`/realtime → conversations/detail screens | Main BE cung cấp peer resolution từ booking/photographer; chat transport lấy `CHAT_API_URL`. Chưa xác minh live service/realtime. |

Contract references: `lens-be/src/features/api/http/` (auth, user, customer, photographer, booking-plan, booking, payments, feedback, media), DTO tương ứng trong `src/features/api/dto/`, response wrapper trong `src/shared/common/interceptors/transform-response.interceptor.ts`.
